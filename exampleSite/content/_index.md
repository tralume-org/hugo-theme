Welcome to the Tralume example site! This page demonstrates the basic capabilities of the Tralume theme.

## Getting Started

1. Edit this page: `content/_index.md`
2. Add posts to the `content/posts/` directory
3. Adjust settings in `hugo.toml` as needed

## Theme Features

- **Material Design 3** design language
- **Acrylic / frosted glass** surfaces
- **Dark / Light / Auto** theme modes
- **Multilingual** support
- **Zero build dependencies** — just Hugo
- **Search**, **friends links**, **comments** and more, ready to use

For full documentation, visit the [Tralume docs](https://tralume.org/docs/).
