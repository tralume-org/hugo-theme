このページでは、ドキュメントとテーマ UI 全体で使用する用語を統一します。

## 基本用語

| 概念               | UI（読者向け）   | ドキュメント/設定（サイト管理者） | 備考                                                               |
| ------------------ | ---------------- | -------------------------------- | ------------------------------------------------------------------ |
| Friends            | Friends          | フレンドリンク                   | "Friends" はページ名です。ドキュメント/設定ではリンクの管理について説明します。 |
| 設定パネル         | 設定             | 設定パネル                       | "設定" はボタンラベルです。"設定パネル" は機能名です。              |
| テーマモード       | テーマモード     | テーマモード                     | 自動 / ライト / ダーク。                                           |
| 読書幅             | 読書幅           | 読書幅                           | 設定パネルで調整可能、ローカルに保存されます。                     |
| アクリル効果       | 不透明度 / ぼかし半径 | アクリル効果                 | "効果" は機能名です。"不透明度" と "ぼかし半径" はスライダーラベル（UI）です。 |
| 不透明度           | 不透明度         | アクリル不透明度                 | アクリル不透明度のスライダーラベルとして使用されます。             |
| ぼかし半径         | ぼかし半径       | ぼかし半径                       | "半径" の表現を維持してください。                                  |
| カスタム背景       | カスタム背景     | カスタム背景                     | 背景ソースと背景ぼかし。                                           |
| テーマシード       | テーマカラー     | テーマシード                     | #RRGGBB 形式のデフォルトアクセントカラー。                         |

## 非推奨（使用しない表現）

| 使用しない表現     | 代わりに使用する表現 |
| ------------------ | -------------------- |
| Appearance mode    | テーマモード         |
| Reader width       | 読書幅               |
| Frosted strength   | アクリル不透明度     |
