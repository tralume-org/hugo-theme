Cette page uniformise la terminologie utilisée dans la documentation et l'interface du thème.

## Termes fondamentaux

| Concept               | Interface (lecteur)     | Docs / config (propriétaire) | Notes                                                                           |
| --------------------- | ----------------------- | ---------------------------- | ------------------------------------------------------------------------------- |
| Amis                  | Amis                    | Liens d'amis                 | « Amis » est un nom de page ; la doc/configuration parle de gérer les liens.    |
| Panneau de paramètres | Paramètres              | Panneau de paramètres        | « Paramètres » est une étiquette de bouton ; « panneau de paramètres » est le nom de la fonctionnalité. |
| Mode de thème         | Mode de thème           | Mode de thème                | auto / clair / sombre.                                                          |
| Largeur de lecture    | Largeur de lecture      | Largeur de lecture           | Réglable dans le panneau de paramètres et enregistrée localement.               |
| Effet acrylique       | Opacité / Rayon de flou | Effet acrylique              | « Effet » est la fonctionnalité ; « Opacité » et « Rayon de flou » sont les étiquettes des curseurs (interface). |
| Opacité               | Opacité                 | Opacité acrylique            | Utilisée comme étiquette du curseur pour l'opacité acrylique.                   |
| Rayon de flou         | Rayon de flou           | Rayon de flou                | Conserver la formulation « rayon ».                                             |
| Arrière-plan personnalisé | Arrière-plan personnalisé | Arrière-plan personnalisé | Source de l'arrière-plan + flou d'arrière-plan.                                 |
| Couleur source du thème | Couleur du thème      | Couleur source du thème      | La couleur d'accentuation par défaut au format #RRGGBB.                         |

## À éviter (terminologie obsolète)

| À éviter         | À utiliser              |
| ---------------- | ----------------------- |
| Mode d'apparence | Mode de thème           |
| Largeur lecteur  | Largeur de lecture      |
| Force du givrage | Opacité acrylique       |
