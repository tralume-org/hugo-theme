本頁統整文件與主題 UI 中的用詞。

## 核心術語

| 概念              | UI（讀者面向）    | 文件 / 設定（站長面向）  | 備註                                                               |
| ----------------- | ------------------- | -------------------------- | ------------------------------------------------------------------ |
| Friends           | Friends             | 友站連結                   | 「Friends」是頁面名稱；文件/設定討論連結管理。                     |
| 設定面板          | 設定                | 設定面板                    | 「設定」是按鈕標籤；「設定面板」是功能名稱。                       |
| 主題模式          | 主題模式            | 主題模式                    | 自動 / 淺色 / 深色。                                               |
| 閱讀寬度          | 閱讀寬度            | 閱讀寬度                    | 可在設定面板中調整，並儲存在本機。                                 |
| 亞克力效果        | 透明度 / 模糊半徑   | 亞克力效果                  | 「效果」是功能；「透明度」與「模糊半徑」是 UI 滑桿標籤。           |
| 透明度            | 透明度              | 亞克力透明度                | 用作亞克力透明度的滑桿標籤。                                       |
| 模糊半徑          | 模糊半徑            | 模糊半徑                    | 保留「半徑」用詞。                                                 |
| 自訂背景          | 自訂背景            | 自訂背景                    | 背景來源 + 背景模糊。                                              |
| 主題種子色        | 主題顏色            | 主題種子色                  | 預設強調色，格式為 #RRGGBB。                                       |

## 避免使用（已棄用的用詞）

| 避免使用         | 改用             |
| ---------------- | ---------------- |
| Appearance mode  | 主題模式         |
| Reader width     | 閱讀寬度         |
| Frosted strength | 亞克力透明度     |
