---
title: 阅读宽度
weight: 30
---

由于每个人的显示器分辨率不同，太宽的行距会增加阅读疲劳，太窄则浪费空间。
通过此配置，你可以设定一个最适合你内容风格的默认宽度（以屏幕宽度的百分比为单位）。

## 配置位置

在站点根目录的 `hugo.toml` 中设置：

```toml
[params.theme]
  # 说明：设置正文区的默认最大宽度（单位为 vw，即屏幕宽度的百分比）。
  # 取值范围：60 到 92 之间的数字。
  # 示例：80 表示正文最多占据屏幕宽度的 80%。
  defaultReaderWidthValue = 80
```

## 特性说明

- **智能限制**：为了保证在各种屏幕上的观感，主题会将该值限制在 60% 到 92% 之间。如果你填写 50，主题会自动调整为 60；填写 100 则调整为 92。
- **响应式适应**：在手机等窄屏幕设备上，主题会自动忽略此配置，让内容铺满屏幕以保证阅读空间。

## 优先级规则

1. **用户手动调节**：用户在设置面板滑动条调整后的宽度会保存在本地。
2. **站点配置**：新用户访问时使用 `defaultReaderWidthValue`。
