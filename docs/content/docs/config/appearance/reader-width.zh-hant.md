title: 閱讀寬度
weight: 30
date: '2026-06-06T00:00:00+08:00'
---

不同的螢幕適合不同的行長度。此設定讓你可以為閱讀區域選擇一個舒適的預設最大寬度（以可視區域寬度的百分比表示）。

## 設定位置

在網站根目錄的 `hugo.toml` 中設定：

```toml
[params.theme]
  # 注意：預設最大閱讀寬度（vw = 可視區域寬度的 %）。
  # 範圍：60 到 92 之間的數字。
  # 範例：80 表示內容區域最寬為 80%。
  defaultReaderWidthValue = 80
```

## 注意事項

- **箝位範圍**：主題將數值限制在 60%–92%，以確保在各種螢幕上有良好的可讀性。
- **回應式設計**：在窄螢幕上（例如手機），此設定會被忽略，讓內容可以使用全寬。

## 優先規則

1. **使用者調整**：透過設定面板選擇的寬度會儲存在本機。
2. **網站設定**：對於新訪客，使用 `defaultReaderWidthValue`。
