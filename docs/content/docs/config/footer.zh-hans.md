在页面最底部的版权信息和 RSS 订阅链接后，追加你自定义的内容。

你可以利用这个功能添加 ICP 备案号、公安联网备案、隐私政策链接、或者友情链接入口。
这些内容会以 `|` 符号作为分隔符排列在 RSS 链接之后。

## 配置位置

在 `hugo.toml` 中设置：

```toml
[params.footer]
  # 说明：定义要在 RSS 链接后追加的条目数组。
  afterRss = [
    # 示例 1：纯文本（适合备案号）
    { text = '京ICP备12345678号' },

    # 示例 2：带链接的条目（适合隐私政策）
    { text = '隐私政策', url = '/privacy/' },

    # 示例 3：使用翻译 Key（如果你有多语言需求）
    { i18n = 'footerLinkContact' , url = '/contact/' }
  ]
```
