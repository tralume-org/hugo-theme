# 内容展示与摘要

控制首页展示的文章数量、`/posts` 列表分页，以及列表页中文章简介（摘要）的长度。

## 首页最新文章上限

为了保持首页整洁，你可以限制显示的最新文章数量。超出部分会通过一个“查看更多”按钮引导用户进入完整的文章列表。

### 配置位置

在 `hugo.toml` 中设置：

```toml
[params.home]
  # 说明：首页展示的最新文章数量。
  recentPostsLimit = 6
```

## 摘要截断长度

在文章列表中，如果文章没有单独的描述，主题会自动抓取文章开头的一段文字作为简介。你可以控制这段文字显示多长。

在 `hugo.toml` 中设置：

```toml
[params]
  # 说明：首页和文章列表卡片中的摘要长度（字符数）。
  articleCardSummaryLength = 160
```

## /posts 分页大小

`/posts` 入口页现在与首页使用同款卡片列表样式，并且默认启用分页。

在 `hugo.toml` 中设置：

```toml
[params.posts]
  # 说明：/posts 每页显示的文章数量；文章总数会按该值自动分多页。
  # 注意：当值小于等于 0 时会回退到默认值 10。
  pageSize = 10
```

## 小技巧

- **手动控制摘要起点**：你可以在文章内容中使用 `<!--more-->` 标记来划分摘要区域（主题会优先用它来生成摘要）。
- **优先使用描述**：如果文章设置了 `description` 参数，主题在首页与 `/posts` 列表会优先使用它作为摘要。
- **分页导航（移动端）**：移动端仅显示“上一页 / 当前页 / 下一页”并合并为一条控件；桌面端显示带省略号的页码条。
