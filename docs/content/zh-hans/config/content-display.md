# 内容展示与摘要

控制首页展示的文章数量，以及列表页中文章简介（摘要）的长度。

## 首页最新文章上限

为了保持首页整洁，你可以限制显示的最新文章数量。超出部分会通过一个“查看更多”按钮引导用户进入完整的文章列表。

### 配置位置

在 `hugo.toml` 中设置：

```toml
[params.home]
  # 说明：首页展示的最新文章数量。
  recentPostsLimit = 6
```

## 摘要截断长度

在文章列表或时间线中，如果文章没有单独的描述，主题会自动抓取文章开头的一段文字作为简介。你可以控制这段文字显示多长。

在 `hugo.toml` 中设置：

```toml
[params]
  # 说明：首页和文章列表卡片中的摘要长度（字符数）。
  articleCardSummaryLength = 160

  # 说明：/posts 时间线页面中的摘要长度（字符数）。
  articleTimelineSummaryLength = 160
```

## 小技巧

- **手动控制摘要起点**：你可以在文章内容中使用 `<!--more-->` 标记来划分摘要区域（主题会优先用它来生成摘要）。
- **优先使用描述**：如果文章设置了 `description` 参数，主题在首页与部分列表（例如时间线）会优先使用它作为摘要。
