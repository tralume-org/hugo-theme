# 亚克力效果

控制页面各元素（如卡片、导航栏）的亚克力效果，以及对应的磨砂强度。

## 配置位置

在站点根目录的 `hugo.toml` 中设置：

```toml
[params.theme]
  # 说明：设置“磨砂强度（透明度）”的默认值（百分比）。
  # 取值范围：0 到 95 之间的数字。
  # 数值越大：亚克力越“实”（更不透明）；数值越小：越“透”。
  defaultGlassStrength = 45
```

## 优先级规则

1. **用户手动调节**：用户可以通过设置面板中的滑动条实时调节透明度与模糊半径，手动调节的结果优先级最高。
2. **站点配置**：新用户访问时使用 `defaultGlassStrength` 作为初始磨砂强度（透明度）。
